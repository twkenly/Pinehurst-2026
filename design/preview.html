Logo Redesign — Three Directions

Same brief across all three: shield, crossed clubs, ball on top, a custom geometric K in place of the serif monogram — pulled a step further from Knollwood's crest than the current mark, while keeping the same silhouette family. Ink sampled directly from the current logo file: #0B3B18.

Note on the 1-color builds: the "hole" areas (the K, the ball's center) are set to match the swatch they're shown on here, using a true SVG mask so they render correctly on any single background — but they're not yet independent of background color. Fine for digital use as-is; a screen-printer or embroiderer should get true vector holes cut before production.
